media

A pane for the SolidOS data browser that plays video and sound and shows pictures with the browser’s own player. A card gives the file name, size, type and length, with Open and Download buttons. It is one module, loaded by link.

Try it

  • Test pattern, MP4 (video) Pane runner SolidOS
  • Test pattern, WebM (video) Pane runner SolidOS
  • Arpeggio, MP3 (audio) Pane runner SolidOS
  • Arpeggio, Ogg Opus (audio) Pane runner SolidOS
  • Panes, SVG (image) Pane runner SolidOS

The page asks before it runs a pane from a site it has not seen. Allow it, and the file opens.

Early days: which formats play is up to the browser, and when one does not, the card says so and gives a link to open it.

The pane: https://solid-panes.github.io/media/media-pane.js
